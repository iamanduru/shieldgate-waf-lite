# Security Policy

## Reporting Security Issues

Do not open public GitHub issues for sensitive security problems.

Report security issues privately to the project maintainer.

## Security Principles

This project follows:

- Secure defaults
- Least privilege
- No secrets in source code
- Safe logging
- Input validation
- Clear auditability
- Defense in depth

## Do Not Commit

Never commit:

- `.env`
- Passwords
- API keys
- Tokens
- Private keys
- Raw request logs
- Customer data
